Låtquiz, till startsidan

Om spelet

Låtquiz är byggt med Claude, en AI från Anthropic, som har skrivit koden utifrån önskemål om hur spelet ska fungera.

Ingen egen server

Spelet är vanliga webbsidor i HTML, CSS och JavaScript på GitHub Pages. Spelledarens webbläsare håller i låtar, svar och poäng, och mobilerna ansluter direkt till den med WebRTC via PeerJS.

Musiken

Spelet öppnar bara en länk till låten i spelledarens Spotify-app, så det behövs ingen inloggning eller koppling till Spotify. Spelarna väljer svar ur en förslagslista där rätt svar blandas med låtar som inte är med.

Kvalitet

Varje ändring kontrolleras automatiskt med tester, HTML-validering, tillgänglighet enligt WCAG 2.2 AA och prestanda i mobilen.
